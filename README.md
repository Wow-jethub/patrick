# Your Path

Interactive partner presentation. Static pages, nothing to build.

- `index.html` — picks the layout by screen and redirects
- `your-path.html` — vertical cut (phone), 29 screens
- `your-path-wide.html` — 16:9 cut (desktop / webinar), 20 screens
- `onboarding/index.html` — "The First Thirty Days" onboarding page (served at `/onboarding/` on jetup-legends.com); expects the `jetup-legends-golden-dynasty.png` logo one level up, which is not in this repo yet

Each page is self-contained: video backgrounds are embedded, no external assets.
