# JetUP Legends — логопак

Утверждённый знак: **Golden Dynasty** (медальон, решение 19.08.2026, исходник `brand/02`).
Все файлы ниже — прозрачные PNG, извлечены из утверждённого растра.
Текстовая часть пересобрана начисто фирменными шрифтами
(Cormorant Garamond SemiBold + Montserrat Medium), не вырезана из генерации.

`_web/` — те же файлы в WebP для сайтов и Claude Design (легче в 5–10 раз).

## Какой файл когда брать

| Задача | Файл |

| Знак на тёмном фоне (видео, сайт, слайды) | `jl-icon-gold-for-dark.png` (2048 / 1024 / 512) |
| Знак на светлом фоне | `jl-icon-antique-for-light.png` |
| Одноцветная печать по светлому | `jl-icon-onyx-mono.png` |
| Одноцветная печать по тёмному / выворотка | `jl-icon-ivory-mono.png` |

| Только текст, светлый фон | `jl-wordmark-for-light.png` |

## Правила (из BRAND_GUIDE)

- Знак ставится **только на обсидиан (#0A0A0A) или на ivory (#F4EADE)** — не на золотую
  плашку, не на пёстрые фото без затемнения.
- Ниже 22 px медальон **меняется на лигатуру**, а не ужимается.
- Не поворачивать, не растягивать, не давать свечение и обводку.
- Золота в кадре не больше 15%.
- Написание всегда `JetUP`.

## Чего здесь нет

- **Вектор (SVG/AI).** Для печати, вышивки и тиснения нужна отрисовка в кривых —
  это Этап 3 плана, растр из генерации не заменяет вектор.
- Версий с короной, серебром, вторым металлом — запрещены брифом.
